# Rectangle Area Calculator

## About the Project

This is a simple Rectangle Area Calculator made using HTML and JavaScript.

## Formula

Area = Length × Width

## What I Learned

- JavaScript variables
- Global scope
- User input using prompt()
- Basic arithmetic operations
- Displaying output using JavaScript

## How It Works

The user enters the length and width.
The JavaScript calculates the area and displays the result.

## Example

Length = 10

Width = 5

Area = 50
